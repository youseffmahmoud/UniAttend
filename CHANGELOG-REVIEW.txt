Important deployment note
-------------------------
Set `APP_ORIGIN` as a Supabase Edge Function secret to the exact deployed website origin
(for example `https://your-site.example`). Deploy the updated function:

    supabase functions deploy admin-create-doctor

Do not expose `SUPABASE_SERVICE_ROLE_KEY` in any browser file. Back up the live
database and validate the supplied SQL migrations against the actual schema before
applying them.
